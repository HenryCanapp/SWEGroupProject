# Productivity App

## Prerequisites
- Node.js (v18+)
- npm
- Expo Go installed on your mobile device

## Getting Started

### Frontend
1. Clone the repo: `git clone https://github.com/HenryCanapp/SWEGroupProject.git`
2. Navigate to the project: `cd productivity-app`
3. Install dependencies: `npm install`
4. Start the dev server: `npx expo start`
5. Scan the QR code with Expo Go on your phone or use the browser
